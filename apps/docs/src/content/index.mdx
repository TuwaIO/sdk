# Introduction

Welcome to the **TUWA SDK** documentation — the official documentation for the TUWA Ecosystem's umbrella SDKs and the server-side Quasar Cloud client.

## What is the TUWA SDK?

This repository provides developers with a seamless integration experience by bundling all TUWA packages (Orbit, Pulsar, Satellite, Nova UI) into easy-to-use, unified points of entry. It is divided into several packages:

1. **`@tuwaio/sdk`** *(Layer 8 — L8)*: The Core Umbrella SDK. Bundles framework-agnostic logic and UI components into clean subpaths.
2. **`@tuwaio/evm-sdk`** *(Layer 9 — L9)*: The EVM Network Adapter SDK. Bundles Ethereum/EVM specific implementations and watchers.
3. **`@tuwaio/solana-sdk`** *(Layer 9 — L9)*: The Solana Network Adapter SDK. Bundles Solana specific implementations and watchers.
4. **`@tuwaio/quasar-sdk`** *(Layer 5 — L5)*: The Node.js & Edge SDK for interacting with the TUWA Quasar Cloud API.

## Dependency Architecture

To prevent dangerous singleton conflicts (like "Multiple instances of React" or Wagmi context errors), the TUWA SDK adopts a strict dependency strategy:

- **Internal Logic** (`orbit`, `pulsar`, `satellite`, `nova`) is hidden inside direct `dependencies`. You never need to install them manually.
- **Web3 Singletons** (`react`, `viem`, `@wagmi/core`, `gill`, `@wallet-standard/*`) are explicitly kept as `peerDependencies`. Your dApp is responsible for installing them alongside the SDK.

## Installation & Quick Start

### 1. Base SDK

Install the core SDK and the required React peer dependencies:

```bash
pnpm add @tuwaio/sdk react react-dom
```

```tsx
import { ConnectButton } from '@tuwaio/sdk/nova-connect';
import { TransactionList } from '@tuwaio/sdk/nova-transactions';
import { useAccount } from '@tuwaio/sdk/satellite';

export function App() {
  const { address } = useAccount();

  return (
    <div>
      <ConnectButton />
      {address && <TransactionList />}
    </div>
  );
}
```

### 2. Network Adapters

Depending on your target blockchain, install the network-specific SDK and its Web3 singletons:

**For EVM:**

```bash
pnpm add @tuwaio/evm-sdk viem @wagmi/core
```

```tsx
import { satelliteEVMAdapter } from '@tuwaio/evm-sdk/satellite';
import { EVMConnectorsWatcher } from '@tuwaio/evm-sdk/nova-connect';

// Mount the EVM providers and watchers
<EVMConnectorsWatcher wagmiConfig={wagmiConfig} />;
```

**For Solana:**

```bash
pnpm add @tuwaio/solana-sdk gill @wallet-standard/react @wallet-standard/app @wallet-standard/ui-core @wallet-standard/ui-registry
```

### 3. Quasar Cloud Client (Server-side)

```bash
pnpm add @tuwaio/quasar-sdk
```

```typescript
import { Quasar, utils } from '@tuwaio/quasar-sdk';

// Initialize the client
const quasar = new Quasar({ secretKey: 'sk_live_...' });
const { txKey } = await quasar.pulsar.syncCreate(transaction);
```
