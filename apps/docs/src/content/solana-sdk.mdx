# Solana Network Adapter (`@tuwaio/solana-sdk`)

`@tuwaio/solana-sdk` is **Layer 9 (L9)** of the TUWA ecosystem architecture — a headless network adapter SDK built on **Gill** and **Wallet Standard** for Solana.

It provides modern Solana RPC connections, standard wallet auto-discovery, and signature tracking adapters without relying on legacy `@solana/web3.js` classes.

---

## 💾 Installation

Install `@tuwaio/solana-sdk` alongside the core SDK and required Solana singletons:

```bash
pnpm add @tuwaio/sdk @tuwaio/solana-sdk gill @wallet-standard/react @wallet-standard/app @wallet-standard/ui-core @wallet-standard/ui-registry
```

---

## 📦 Subpath Entrypoints

`@tuwaio/solana-sdk` provides clean subpaths ordered by ecosystem layer:

```tsx
// 1. Multi-Chain Primitives (Orbit Solana)
import { createSolanaRPC } from '@tuwaio/solana-sdk/orbit';

// 2. Wallet Connection State (Satellite Solana)
import { satelliteSolanaAdapter } from '@tuwaio/solana-sdk/satellite';

// 3. Transaction Tracking Engine (Pulsar Solana)
import { pulsarSolanaAdapter } from '@tuwaio/solana-sdk/pulsar';

// 4. Connect UI Auto-Discovery (Nova Connect Solana)
import { SolanaConnectorsWatcher } from '@tuwaio/solana-sdk/nova-connect';

// 5. CAIP-122 Authentication (SIWX Solana)
import { createSolanaSiwxSigner } from '@tuwaio/solana-sdk/siwx';
```
