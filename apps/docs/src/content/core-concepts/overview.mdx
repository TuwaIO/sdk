# Layer Architecture & Overview

The **TUWA Ecosystem** is designed around a strict, multi-tiered architecture that decouples low-level Web3 communication, state management, UI rendering, and cloud synchronization.

---

## 🏛️ Ecosystem Layer Model (L1 – L9)

```
+-----------------------------------------------------------------------------------+
| L8: Core SDK (@tuwaio/sdk)                                                        |
|     Modular Subpaths: /pulsar, /satellite, /orbit, /nova-connect, /nova-transactions|
+------------------------------------+----------------------------------------------+
| L9: EVM Adapter SDK (@tuwaio/evm-sdk)| L9: Solana Adapter SDK (@tuwaio/solana-sdk)|
|     Wagmi/Viem + EVMConnectorsWatcher|     Gill/Wallet Standard + SolanaWatcher  |
+------------------------------------+----------------------------------------------+
| L5: Cloud Engine Client (@tuwaio/quasar-sdk)                                      |
|     Server-Side Node.js/Edge + QuasarAuthBridge                                  |
+-----------------------------------------------------------------------------------+
| L1-L4 & L6-L7 Headless & UI Primitives                                            |
|     Orbit (L1-L3), Pulsar (L4), Satellite (L4), Nova UI (L6-L7)                    |
+-----------------------------------------------------------------------------------+
```

### Layer Breakdown

1. **L1 – L3 (Orbit Utils)** — Low-level, framework-agnostic multi-chain communication primitives.
2. **L4 (Pulsar & Satellite Core)** — Headless state machines for transaction tracking and wallet session lifecycle.
3. **L5 (Quasar Cloud Engine)** — Server-side Node.js & Edge client (`@tuwaio/quasar-sdk`) for indexing, cloud sync, and cryptographic signatures.
4. **L6 – L7 (Nova UI Kit)** — Pure view layer React components, modals, toasts, and design tokens.
5. **L8 (Core SDK)** — The main client entrypoint (`@tuwaio/sdk`) bundling logic and UI into modular subpaths.
6. **L9 (Network Adapters)** — Ecosystem adapters (`@tuwaio/evm-sdk` and `@tuwaio/solana-sdk`) providing Web3 singletons, transports, and background state watchers.

---

## ⚡ Zero UI Bloat & Subpath Guarantee

To guarantee zero bundle bloat and prevent dangerous Web3 singleton conflicts (such as duplicate instances of React, Wagmi, or Wallet Standard context), all client SDK packages enforce a **100% Subpath-Only Policy**.

Direct imports from package roots (`from '@tuwaio/sdk'`) are disabled. Developers import only the specific subpaths required:

```tsx
import { ConnectButton } from '@tuwaio/sdk/nova-connect';
import { TransactionList } from '@tuwaio/sdk/nova-transactions';
import { useAccount } from '@tuwaio/sdk/satellite';

import '@tuwaio/sdk/styles/all.css';
```
