# Layer Architecture & Overview

The **TUWA Ecosystem** is built around a multi-tiered architecture that decouples low-level Web3 primitives, state management, UI rendering components, and cloud transaction indexing.

---

## 🏛️ Ecosystem Layer Model (L1 – L9)

```
+-----------------------------------------------------------------------------------+
| L8: Core SDK (@tuwaio/sdk)                                                        |
|     Modular Subpaths: /orbit, /satellite, /pulsar, /nova-connect, /nova-transactions|
+------------------------------------+----------------------------------------------+
| L9: EVM Adapter SDK (@tuwaio/evm-sdk)| L9: Solana Adapter SDK (@tuwaio/solana-sdk)|
|     Wagmi/Viem + EVMConnectorsWatcher|     Gill/Wallet Standard + SolanaWatcher  |
+------------------------------------+----------------------------------------------+
| L5: Cloud Engine Client (@tuwaio/quasar-sdk)                                      |
|     Server-Side Node.js/Edge + QuasarAuthBridge                                  |
+-----------------------------------------------------------------------------------+
| L1-L4 & L6-L7 Headless & UI Primitives                                            |
|     Orbit (L1-L3), Satellite (L4), Pulsar (L4), Nova UI (L6-L7)                    |
+-----------------------------------------------------------------------------------+
```

### Layer Breakdown

1. **L1 – L3 (Orbit Utils)** — Low-level, framework-agnostic multi-chain communication primitives and adapters (`OrbitAdapter.EVM`, `OrbitAdapter.SOLANA`).
2. **L4 (Satellite & Pulsar Engine)** — Headless state machines for wallet connectivity (Satellite) and transaction tracking lifecycles (Pulsar).
3. **L5 (Quasar Cloud Engine)** — Server-side Node.js & Edge client (`@tuwaio/quasar-sdk`) for cloud transaction indexing, history pagination, and authentication verification.
4. **L6 – L7 (Nova UI Kit)** — View layer React components (`ConnectButton`, `TxActionButton`), modals, toasts, and visual design tokens.
5. **L8 (Core SDK)** — The umbrella client entrypoint (`@tuwaio/sdk`) packaging all client layers into version-aligned subpaths.
6. **L9 (Network Adapters)** — Specialized network packages (`@tuwaio/evm-sdk` and `@tuwaio/solana-sdk`) providing network singletons, transports, and background state watchers.

---

## ⚡ Zero UI Bloat & Subpath Guarantee

To prevent bundle bloat and Web3 context conflicts, all TUWA client SDK packages enforce a **100% Subpath-Only Policy**.

Direct imports from package root (`from '@tuwaio/sdk'`) are disabled. Developers import only the specific subpaths required:

```tsx
import { ConnectButton } from '@tuwaio/sdk/nova-connect';
import { TxActionButton } from '@tuwaio/sdk/nova-transactions';
import { useSatelliteConnectStore } from '@tuwaio/sdk/satellite';

import '@tuwaio/sdk/styles/all.css';
```
