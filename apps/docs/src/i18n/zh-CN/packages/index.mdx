# 软件包

TUWA SDK 包含四个包。`@tuwaio/sdk`（**L8**）通过子路径重导出 Orbit Utils、Pulsar、Satellite Connect、SIWX 与 Nova UI Kit 的客户端包，其 **L9** 扩展包 `@tuwaio/evm-sdk` 与 `@tuwaio/solana-sdk` 重导出这些项目的 EVM 与 Solana 包。`@tuwaio/quasar-sdk`（**L5**）是 Quasar API 的客户端。

被重导出的包在各自项目的站点上编写文档，因此三个重导出包的页面就是它们的 README：每个 README 列出其子路径，并附有指向每个子路径背后那个包的参考文档的链接。`@tuwaio/quasar-sdk` 的页面是它的 README，随后是其全部导出的完整列表；每个函数、类、类型与常量页面都根据 TypeScript 源码及其 JSDoc 生成。包的 README 与参考文档均为英文。`@tuwaio/quasar-sdk` 有两个入口（`@tuwaio/quasar-sdk` 与 `@tuwaio/quasar-sdk/react`），分别作为独立模块编写文档。
