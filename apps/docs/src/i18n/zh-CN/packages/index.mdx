# 软件包

TUWA SDK 包含三个包。`@tuwaio/sdk`（**L8**）通过子路径重导出 Orbit Utils、Pulsar、Satellite Connect、SIWX 与 Nova UI Kit 的客户端包，其 **L9** 扩展包 `@tuwaio/evm-sdk` 与 `@tuwaio/solana-sdk` 重导出这些项目的 EVM 与 Solana 包。

被重导出的包在各自项目的站点上编写文档，因此每个包的页面就是它的 README：它列出其子路径，并附有指向每个子路径背后那个包的参考文档的链接。包的 README 与参考文档均为英文。支付是建立在 SDK 之上的独立模块：[`@tuwaio/payments-sdk`](https://payments.docs.tuwa.io/?path=/docs/packages-payments-sdk-overview--docs)。
