# Пакети

TUWA SDK складається з трьох пакетів. `@tuwaio/sdk` (**L8**) реекспортує клієнтські пакети Orbit Utils, Pulsar, Satellite Connect, SIWX і Nova UI Kit через підшляхи, а його доповнення **L9** `@tuwaio/evm-sdk` і `@tuwaio/solana-sdk` реекспортують їхні пакети для EVM і Solana.

Реекспортовані пакети задокументовано на сайтах їхніх проєктів, тож сторінка кожного пакета — це його README: він перелічує свої підшляхи з посиланням на довідник пакета, що стоїть за кожним із них. README пакетів і довідник подано англійською. Платежі — окремий модуль поверх SDK, [`@tuwaio/payments-sdk`](https://payments.docs.tuwa.io/?path=/docs/packages-payments-sdk-overview--docs).
