# Пакети

TUWA SDK складається з чотирьох пакетів. `@tuwaio/sdk` (**L8**) реекспортує клієнтські пакети Orbit Utils, Pulsar, Satellite Connect, SIWX і Nova UI Kit через підшляхи, а його доповнення **L9** `@tuwaio/evm-sdk` і `@tuwaio/solana-sdk` реекспортують їхні пакети для EVM і Solana. `@tuwaio/quasar-sdk` (**L5**) — клієнт API Quasar.

Реекспортовані пакети задокументовано на сайтах їхніх проєктів, тож сторінки трьох пакетів реекспорту — це їхні README: кожен перелічує свої підшляхи з посиланням на довідник пакета, що стоїть за кожним із них. Сторінка `@tuwaio/quasar-sdk` — це його README, за яким іде повний список його експортів; сторінку кожної функції, класу, типу й константи згенеровано з вихідного коду TypeScript та його JSDoc. README пакетів і довідник подано англійською. `@tuwaio/quasar-sdk` має дві точки входу, `@tuwaio/quasar-sdk` і `@tuwaio/quasar-sdk/react`, описані як окремі модулі.
