# TUWA SDK — Documentation Site

Source of the official TUWA SDK documentation at **[sdk.docs.tuwa.io](https://sdk.docs.tuwa.io)**. It covers `@tuwaio/sdk`, `@tuwaio/evm-sdk` and `@tuwaio/solana-sdk`.

The site follows the TUWA **Packages** layout used by Orbit Utils, SIWX, Satellite Connect and Pulsar: a hand-written Introduction plus one page per npm package. Guides that combine several TUWA projects (the full-stack React app, Quasar sync) and the Quasar documentation live in the docs hub at [docs.tuwa.io](https://docs.tuwa.io).

---

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Docs theme:** Nextra 4 (`nextra`, `nextra-theme-docs`)
- **Shared TUWA UI:** `@tuwaio/docs-ui` (navbar, footer, logo, design tokens, the layout and page route in three languages)
- **Styling:** Tailwind CSS 4. The look of the site (paper and ink: the colors of both themes, Geist and Geist Mono, square corners) comes from the stylesheet of `@tuwaio/docs-ui`; `src/styles/app.css` only imports it and sets no color of its own
- **Search:** Pagefind (built in the `postbuild` step)
- **Package pages:** a page script in [`package-pages/`](./package-pages)
- **Deployment:** Vercel

---

## 🚀 Getting Started

Install dependencies from the **monorepo root** (this also builds all packages through the root `postinstall` script):

```bash
pnpm install
```

Start the dev server from the monorepo root:

```bash
pnpm --filter @tuwaio/sdk-docs dev
```

The site runs at **[http://localhost:3000](http://localhost:3000)**.

## 🗂 Content Structure

```
apps/docs/
├── src/content/
│   ├── _meta.tsx              # Sidebar: Introduction, Packages, Guides and Quasar (links to docs.tuwa.io)
│   ├── index.mdx              # Introduction (hand-written)
│   └── packages/              # GENERATED — do not edit by hand
│       ├── _meta.tsx          # Copied from package-pages/meta/_meta.tsx
│       ├── index.md           # Packages overview (package-pages/packages-overview.md)
│       ├── sdk/index.md       # README of @tuwaio/sdk
│       ├── evm-sdk/index.md   # README of @tuwaio/evm-sdk
│       └── solana-sdk/index.md # README of @tuwaio/solana-sdk
├── src/i18n/                  # Ukrainian and Chinese translations of the hand-written pages (see Languages)
└── package-pages/
    ├── meta/                      # Sidebar labels, copied over the generated tree (same relative paths)
    ├── packages-overview.md       # Intro text of the /packages page
    ├── packagePages.mjs           # Writes the overview page and the three README pages
    └── stripBadges.mjs            # Removes the badge lines of the READMEs
```

Hand-written pages are MDX files in `src/content`; the folder structure maps to URLs, and `_meta.tsx` files control sidebar titles and order. The **Introduction** (`index.mdx`) explains what the SDK is, where it fits in TUWA, its principles, the packages and the installation, and links to the package pages and guides instead of repeating code.

## 🌐 Languages

The site is in **English**, **Українська** and **简体中文**, as the [docs hub](https://docs.tuwa.io): the translated pages have their own URLs (`/uk`, `/zh-CN`; English has no prefix), the package READMEs and the reference keep one English URL, the language switch and the theme switch sit in the navbar, and the reader's choice is kept in `localStorage` (`tuwa-locale`, forgotten after 30 days; no cookie). The layout (`DocsLayout`) and the page route (`createDocsPage`) come from `@tuwaio/docs-ui`, with the interface texts and the common sidebar titles.

```
src/i18n/
├── pages.ts                 # Translated pages by route ('/' and '/packages')
├── mdx.d.ts                 # Types of the imported MDX files
├── uk/
│   ├── index.mdx            # Translates src/content/index.mdx
│   └── packages/index.mdx   # Translates the generated src/content/packages/index.md
└── zh-CN/                   # The same files in Simplified Chinese
```

Only the hand-written pages are translated; package READMEs and the API reference stay in English in every language, with a short note in the reader's language. The translated packages overview says this in a sentence that its English page does not have; apart from it, a translation says what its English page says. A translation keeps the code blocks of its English page unchanged and in the same order, the heading levels with the English heading ids (`## 💾 Встановлення [#-installation]`, so anchors work in every language) and the same links. `pnpm i18n:check` (also part of `pnpm docs:gen` and of the build) checks it:

```bash
pnpm --filter @tuwaio/sdk-docs i18n:check
```

## 📦 Packages Pages

Everything under `src/content/packages` is generated by `pnpm docs:gen` (run from the monorepo root; it also runs in the pre-commit hook):

- **Re-export packages:** `@tuwaio/sdk`, `@tuwaio/evm-sdk` and `@tuwaio/solana-sdk` add no code of their own, and their exports are documented on the sites of the re-exported projects. Their page is their README, copied by `package-pages/packagePages.mjs`; each README lists its subpaths with a link to the reference behind every one of them.
- **Source of truth:** the package READMEs. Never edit the generated Markdown.
- **README rules:** use absolute URLs for links (Nextra cannot render relative targets), and do not hand-write lists of exports or signatures.

## 🚀 Deployment

The site is deployed to **Vercel**. The Pagefind search index is generated in the `postbuild` step of `apps/docs/package.json` and needs no extra configuration.
